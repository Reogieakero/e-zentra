# Zentra — Website (Frontend) Modules

A friendly guide to the Zentra website — the pages and screens people open in
their browser. Written for non-technical users. Each module below has its own
page explaining what it does and what is working.

## How to use this guide

- Every file explains **one module** (one part of the website).
- At the top of each page is the status: **DONE** (finished & working),
  **PARTIAL** (some parts working), or **PLANNED** (not built yet).
- "Done" means the screen is connected to the server behind it, so the data is
  real and current.

## The website at a glance

1. **Sign up** — Choose Teacher, Student, or Parent and follow the on-screen
   steps. The account is reviewed before it's activated.
2. **Sign in** — Pick the Student, Parent, or Staff portal and sign in with your
   email and password (or with Google).
3. **Forgot / Reset password** — Ask for a link by email, then choose a new password.
4. **Principal's Dashboard** — Today's numbers all in one place: enrollment,
   attendance, action items, and documentation; plus the at-risk students, quick
   actions like "Add Student," the ADM items waiting for approval, and charts of
   how each section is doing.
5. **Students** — Look up any student, see their class and section, and open
   their full profile.
6. **Attendance** — Daily or monthly view of who came to class; filter by grade
   and section; see which sections are doing well and which need help.
7. **Reports** — Two pages: an **attendance report** (stat cards, trend chart,
   table, and plain-language insights) and a **needs-attention** page listing the
   under-70% or at-risk students with a button to alert that student's class
   adviser.
8. **SF10 report cards** — Search and browse students by name, grade, status,
   and school year.
9. **Backups & Export** — Connect Google Drive so the school's data is backed
   up and can be exported as Excel and PDF files.

On every screen, the left menu helps you move around, and the top bar always
shows you who you are (for example Principal) and where you are (for example,
Attendance).
